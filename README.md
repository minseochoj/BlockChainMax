# BlockChainMax

Intelligent network architecture enables secure, real-time data processing and auto-scaling within a modular, extensible blockchain platform framework.

With BlockChainMax, you get a lightweight tool that stays out of your way.

**What you get**

- Intelligent network architecture enables secure,
- real-time data processing and auto-scaling
- within a modular, extensible blockchain

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockChainMax.git`
2. `cd BlockChainMax`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure BlockChainMax, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
